# Practice problems

| Action | Shortcut |
|--------|----------|
| Run your code | `Ctrl+Enter` |
| Check against tests | `Ctrl+Shift+Enter` |
| Indent / dedent | `Tab` / `Shift+Tab` |

Your code is saved automatically, so you can switch problems and come back later.

Some tests are **hidden**, so your solution has to work in general, not just for the examples.
